# Project Kickoff Notes

This is a **Markdown** file. Markdown formatting is converted into editable rich text when you upload it.

## Supported formatting

- **Bold text** using double asterisks
- *Italic text* using single asterisks
- ***Bold and italic*** together
- Bullet lists like this one

## Text sizes

Lines starting with `#` become headings:

### This is a Heading 3

Normal paragraphs stay as regular text.

> Note: Markdown has no syntax for underline. Select text after importing and press Ctrl+U to underline it.
